# เสียงของเกม (Phase 6)
เกมมีโค้ดรองรับเสียงครบแล้ว และตอนนี้ใช้ **เสียงสังเคราะห์ชั่วคราว** (สร้างด้วยโค้ดใน `scripts/sfx_synth.gd`) ให้ได้ยินไปก่อน
**วางไฟล์เสียงจริงในโฟลเดอร์นี้โดยตั้งชื่อตาม id ด้านล่าง** (`.ogg` แนะนำ / `.wav` / `.mp3`) เกมจะใช้ไฟล์แทนเสียงสังเคราะห์เองโดยไม่ต้องแก้โค้ด
- เสียงที่ทำเครื่องหมาย **[loop]** ควรเป็นไฟล์ที่วนต่อเนื่องได้ไม่สะดุด (โค้ดจะตั้ง loop ให้เอง)
- เสียงสั้นๆ ความยาวตามคำอธิบาย (ส่วนใหญ่ < 1 วินาที) / ไม่ต้องใส่ครบทุกตัว ตัวไหนไม่มีไฟล์จะใช้เสียงสังเคราะห์
- แหล่งเสียงฟรีที่นิยม: freesound.org, kenney.nl (CC0), opengameart.org, sfxr/jsfxr (สร้างเอง) — **อย่าลืมใส่เครดิตใน README**
- ปรับความดังของแต่ละเสียงในโค้ดที่ `main.gd` (`sfx.play("id", volume_db)`) หรือ normalize ไฟล์ให้ดังใกล้เคียงกัน

| id (ชื่อไฟล์) | ใช้เมื่อ |
| --- | --- |
| `ambient` | เสียงบรรยากาศโรงขยะวนตลอด (ทุ้ม ต่ำ น่ากลัว) [loop] |
| `motor` | มอเตอร์เครนตอนขยับ [loop] |
| `rain` | เสียงฝนตก [loop] |
| `ui_click` | คลิกปุ่ม/ช่อง item |
| `release` | ปล่อยชิ้นขยะ |
| `clunk` | ตะขอเครนคาบชิ้นใหม่ |
| `impact_light` | ขยะกระแทกเบา |
| `impact_heavy` | ขยะกระแทกหนัก (ตู้เย็น ลังเหล็ก) |
| `fail` | เสียชิ้นขยะ (หลุดขอบ/ตกพื้น/กองล้ม) |
| `insured` | ประกันจ่ายแทน |
| `item_get` | ได้ item |
| `item_use` | ใช้ item สำเร็จ |
| `deny` | ใช้ item ไม่ได้ |
| `blip` | boss พูด (ต่อ 1 ตัวอักษร สั้นมาก) |
| `warn` | เตือนลม/แผ่นดินไหวกำลังมา |
| `wind` | ลมกระโชก |
| `rumble` | แผ่นดินไหว |
| `buzz` | ไฟกะพริบ |
| `pass` | ผ่านวัน |
| `fired` | โดนไล่ออก |
| `ending` | ฉากจบ (หลอน) |
