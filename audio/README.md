# เสียงของเกม
เสียงทั้งหมด**ออกแบบด้วยโค้ด** (`_synth()` ใน `scripts/sfx.gd` ใช้ตัวช่วยจาก `scripts/sfx_synth.gd`) แล้ว **"อบ" เป็นไฟล์ `.wav` ในโฟลเดอร์นี้**
ด้วย `tools/bake_sfx.gd` เพื่อให้เกมโหลดไฟล์ได้ทันทีโดยไม่ต้องสังเคราะห์ตอนเปิด (เดิมหน้า title กระตุก ~0.3 วินาที)

**แก้เสียง:** แก้ `_synth()` → รัน
```bash
godot --headless --path . -s tools/bake_sfx.gd   # เขียนทับ audio/*.wav
godot --headless --path . --import               # import ไฟล์ใหม่
```
- ไฟล์ `.wav.import` ตั้ง `compress/mode=0` (PCM ไม่บีบอัด — ค่าเริ่มต้นของ Godot คือ QOA) และ `edit/loop_mode=2` (วน) ให้ `ambient` `motor` `rain`
  **ถ้าเพิ่มเสียงใหม่ต้องแก้ 2 ค่านี้ใน `.import` ของมันด้วย**
- ลบไฟล์ `.wav` ทิ้ง = เกมกลับไปสังเคราะห์สดตอนรัน / วางไฟล์ `.ogg` / `.mp3` ชื่อเดียวกันแทนได้โดยไม่ต้องแก้โค้ด
- ปรับความดังของแต่ละเสียงในโค้ดที่ `main.gd` (`sfx.play("id", volume_db)`)

| id (ชื่อไฟล์) | ใช้เมื่อ |
| --- | --- |
| `ambient` | เสียงบรรยากาศโรงขยะวนตลอด (ทุ้ม ต่ำ น่ากลัว) [loop] |
| `motor` | มอเตอร์เครนตอนขยับ [loop] |
| `rain` | เสียงฝนตก [loop] |
| `ui_click` | คลิกปุ่ม/ช่อง item |
| `release` | ปล่อยชิ้นขยะ |
| `clunk` | ตะขอเครนคาบชิ้นใหม่ |
| `impact_light` | ขยะกระแทกเบา |
| `impact_heavy` | ขยะกระแทกหนัก (ตู้เย็น ลังเหล็ก) |
| `fail` | เสียชิ้นขยะ (หลุดขอบ/ตกพื้น/กองล้ม) |
| `insured` | ประกันจ่ายแทน |
| `item_get` | ได้ item |
| `item_use` | ใช้ item สำเร็จ |
| `deny` | ใช้ item ไม่ได้ |
| `blip` | boss พูด (ต่อ 1 ตัวอักษร สั้นมาก) |
| `warn` | เตือนลม/แผ่นดินไหวกำลังมา |
| `wind` | ลมกระโชก |
| `rumble` | แผ่นดินไหว |
| `buzz` | ไฟกะพริบ |
| `pass` | ผ่านวัน |
| `fired` | โดนไล่ออก |
| `ending` | ฉากจบ (หลอน) |
